# 실내자전거 트래커 ↔ 구글 시트 연동 설정

사용자와 운동 기록을 **내 구글 드라이브의 스프레드시트**에 저장해서, 휴대폰·태블릿·PC 어디서든 같은 기록을 보게 하는 설정입니다.
처음 한 번, 약 10분이면 끝나요. 비용은 들지 않아요. PC에서 하는 것이 편해요.

---

## 1. 스프레드시트 만들기

1. https://sheets.google.com 에 접속해서 **빈 스프레드시트(+)** 를 만듭니다.
2. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 **실내자전거 기록** 으로 바꿉니다.

## 2. 연결 스크립트 붙여넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다. 새 창이 열려요.
2. 편집기에 있는 `function myFunction() { }` 를 **모두 지웁니다.**
3. 아래 주소의 코드를 **전부 복사해서** 붙여넣습니다.
   👉 https://raw.githubusercontent.com/wbhongb01/indoor-bike/main/google-sheets/Code.gs
4. 코드 맨 위의 이 줄에서 따옴표 안을 **가족끼리만 아는 비밀번호**로 바꿉니다.
   ```js
   const FAMILY_KEY = '여기에-가족-비밀번호';
   ```
   예: `const FAMILY_KEY = 'ourbike2026!';`
5. **💾 저장** 을 누릅니다 (또는 `Ctrl + S`).

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 파란 버튼 **배포 → 새 배포** 를 누릅니다.
2. "유형 선택" 옆 **⚙ 톱니바퀴 → 웹 앱** 을 고릅니다.
3. 아래처럼 설정합니다.
   | 항목 | 값 |
   |---|---|
   | 설명 | 실내자전거 (아무거나) |
   | 다음 사용자 인증 정보로 실행 | **나** (내 이메일) |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |
4. **배포** → **액세스 승인** → 내 구글 계정을 고릅니다.
5. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용** 을 누릅니다.
   - 내가 방금 붙여넣은 내 스크립트라서 나오는 안내예요. 이 스크립트는 **이 스프레드시트만** 읽고 씁니다.
6. 화면에 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 **복사**합니다.

## 4. 앱에서 연결하기 (기기마다 한 번씩)

1. 실내자전거 트래커(https://is.gd/indoorbike) → **설정** 탭 → **구글 시트 연동**
2. **연결 주소**에 복사한 웹 앱 URL을, **가족 비밀번호**에 2-4에서 정한 비밀번호를 넣고 **연결하기**
3. 이 기기에만 있던 기록이 있으면 "시트에 합칠까요?"라고 물어봐요 → **확인**
   - 같은 이름의 사용자는 하나로 합쳐집니다.
   - 주소 칸에 붙여넣기가 안 되면 옆의 **[붙여넣기]** 버튼을 누르세요. 배포 ID(`AKfy…`)만 붙여넣어도 주소로 바꿔 줘요.
4. **다른 휴대폰·태블릿은 연결 링크로 하면 쉬워요.** 연결된 기기의 설정 → **다른 기기 연결 링크** 를 눌러 카톡 등으로 보내고, 다른 기기에서 그 링크를 열면 주소와 비밀번호가 자동으로 채워져요. **연결하기** 만 누르면 끝이에요.
   - 링크에는 가족 비밀번호가 들어 있으니 가족에게만 보내세요.
   - 사용자를 다시 만들 필요가 없어요.

**백업 파일로 연결하기:** 연결된 기기에서 설정 → **백업 파일 내보내기** 를 누르면 "연결 정보도 넣을까요?"라고 물어봐요. **확인** 을 누르면 파일에 시트 주소와 비밀번호가 함께 들어가요. 그 파일을 다른 기기에서 **백업 불러오기** 하면 시트 연결과 사용자·기록·계산 설정이 한 번에 맞춰져요.
- 이미 연결된 기기에서 백업을 불러오면, 백업의 사용자·기록·계산 설정(바퀴 둘레·기어비·목표 시간)이 **시트에 합쳐져요.** 같은 기록은 한 번만 저장돼요.
- 연결 정보가 든 백업 파일은 가족에게만 보내세요.

연결되면 위쪽에 ☁ 구름 아이콘이 생겨요.
- 🟢 초록 점: 동기화됨
- 🟡 노란 점: 보내는 중
- 🔴 빨간 점: 확인 필요 (누르면 설정 화면으로 이동)

## 시트 사용법

연결하면 탭 4개가 자동으로 생겨요.

| 탭 | 내용 |
|---|---|
| **운동기록** | 운동 한 번에 한 줄. 최근 기록이 맨 위 |
| **월별 요약** | 월·사용자별 운동 횟수, 시간, 거리, 칼로리 합계 (자동 계산) |
| **사용자** | 가족 구성원 정보 (이름, 체중 등) |
| **설정** | 바퀴 둘레, 기어비, 하루 목표 시간 |

- **시트에서 직접 고쳐도 돼요.** 날짜, 운동시간(분), 거리, 칼로리 같은 값을 고치면 앱에 반영돼요. 사용자 탭에서 이름을 바꿔도 반영돼요.
- **기록을 직접 추가할 수도 있어요.** 운동기록 탭 맨 아래 빈 줄에 `날짜`(예: `2026-11-20 07:30`), `사용자`(사용자 탭의 이름과 똑같이), `운동시간(분)`, `거리(km)`, `칼로리(kcal)` 만 적으면 나머지는 자동으로 채워져요.
- **줄을 지우면** 그 기록이 앱에서도 지워집니다.
- `기록ID`, `사용자ID`, `시작시각(ISO)` 칸은 **고치지 마세요** (앱이 기록을 구분하는 값이에요).
- 시트에서 고친 내용은 앱을 열 때, 5분마다, 또는 설정의 **지금 동기화** 를 누를 때 반영돼요.

## 자주 묻는 문제

| 화면에 나온 말 | 해결 방법 |
|---|---|
| 가족 비밀번호가 맞지 않아요 | 앱에 넣은 비밀번호가 스크립트의 `FAMILY_KEY` 와 똑같은지 확인 (대소문자 구분) |
| FAMILY_KEY(가족 비밀번호)를 바꾼 뒤 … 다시 배포하세요 | 비밀번호를 바꾸고 저장한 뒤, 아래 "스크립트를 고쳤을 때" 순서로 새 버전 배포 |
| 응답을 읽지 못했어요 | 배포 설정의 "액세스 권한이 있는 사용자"가 **모든 사용자** 인지 확인. 회사·학교 구글 계정은 막혀 있을 수 있으니 개인 계정을 쓰세요 |
| 시트에 연결하지 못했어요 | 인터넷 연결과 주소(…/exec 로 끝나는지) 확인 |
| 시트의 날짜·시간이 몇 시간씩 틀려요 | 시트 메뉴 **파일 → 설정 → 시간대** 를 `(GMT+09:00) 서울` 로 |

- **인터넷이 끊겨도 괜찮아요.** 운동 기록은 그 기기에 보관해 두었다가, 연결되면 자동으로 시트에 보내요.

### 스크립트를 고쳤을 때 (비밀번호 변경, 새 버전 코드 붙여넣기)
**배포 → 배포 관리 → ✏ 편집 → 버전: 새 버전 → 배포**
이렇게 하면 웹 앱 주소가 **그대로** 유지돼요. ("새 배포"를 다시 누르면 주소가 바뀌어서, 모든 기기에서 다시 연결해야 해요.)

## 보안 안내
- 스프레드시트는 **내 구글 드라이브에 비공개**로 있어요. 시트를 공유하지 않는 한 다른 사람은 볼 수 없어요.
- 앱은 **웹 앱 주소와 가족 비밀번호를 둘 다** 알아야 기록을 읽고 쓸 수 있어요. 비밀번호는 가족끼리만 공유하세요.
- 비밀번호는 각 기기의 브라우저에만 저장돼요. 백업 파일이나 GitHub 코드에는 들어가지 않아요.
